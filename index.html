Overview

Root Finding Lab compares five numerical methods for solving f(x) = 0. The Fall 2025 CS2008 Numerical Computing study uses seven analytic equations across eight intervals, including a double root, a flat initial derivative, and a cube root with a vertical tangent.

The equations, derivatives, intervals, seed choices, and reference roots are defined in Python. The experiments run without a dataset download.

Results

In the saved strict-residual benchmark, 14 of 15 runs reached |f(x)| ≤ 10⁻¹⁰. The f3 Newton trial stopped at x = 1 with an unusable derivative. Secant met the threshold at x ≈ 3.577152, outside [0, 2]. The hybrid recovered via bisection and reached the intended root near 0.1118325592.

Residual and position error tell different stories

On the double root, Newton residuals below 10⁻⁸ coexist with position errors above 10⁻⁵. The observed order falls from roughly two at simple roots to one here.

Benchmark protocol. The timings report the median of seven batches of 200 calls. The experiment disables step and bracket stops so an accepted run actually reaches the residual threshold. Compare time alongside root location and exit status.

These figures and CSVs are saved results. Run the notebook or experiment command to recompute them.

Desktop Workbench

Run any of the eight intervals with adjustable seeds and tolerances. The desktop app plots the function and error history, reports whether the result lies in the assigned interval, and exports the trace with step type and bracket width.

.venv\Scripts\python.exe -m rootlab.desktop

With the project folder on your computer and dependencies installed, run the command above or double-click launch_workbench.cmd. The desktop source and command-line runner are included.

Reproduce a seed-sensitive case

.venv\Scripts\python.exe -m rootlab.workbench --case f3 --method Newton --seeds 0.2 --strict --tol-f 1e-10

The default Newton seed on f3 is 1, where the derivative vanishes. Starting at 0.2 reaches the smaller root inside the assigned interval.

Setup

From the repository root in PowerShell, create the Python environment, run the tests, and write fresh results.

python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m rootlab.experiments --output build/results

Open the study notebook in your Jupyter editor using that environment to rerun the plots and tables.

Limitations

Bracketing assumes continuity and an endpoint sign change or exact endpoint root. Open methods can leave the assigned interval, and local fixed-point slopes depend on the map and seed. Near the f5 double root, a small residual can coexist with substantial error in x. Timing varies by machine and includes trace recording.
